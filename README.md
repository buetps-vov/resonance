# Voyage of Visuals: Resonance

Static site for the BUET Photographic Society annual exhibition.

## Hosting on GitHub Pages

1. Push **the contents of this folder** to your repository root (not the folder itself).
2. Repo Settings → Pages → Source: *Deploy from a branch* → branch `main`, folder `/ (root)`.
3. Wait a minute, then open `https://<user>.github.io/<repo>/`.

`index.html` redirects to `Home.dc.html`.

Keep `.nojekyll` in the repo — without it GitHub skips files that start with a dot.

## Pages

- `Home.dc.html` — call for photos, theme, submission info
- `Events.dc.html` — upcoming and past exhibitions
- `About.dc.html` — society history
